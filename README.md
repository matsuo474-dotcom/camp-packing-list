# 持ち物チェック

家族で共有できる、持ち物チェックリストです。

- リンクを開けばそのまま使えます（合言葉・ログイン不要）
- チェック・追加・削除は、開いている全員の画面にリアルタイムで反映されます（Firebase Realtime Database 使用）
- リストを複数作れます（キャンプ、買い物、旅行など）
- アイテムは親子2階層のツリー形式。親をチェックすると子がまとめてチェックされます
- 最初のリスト「キャンプ」には定番アイテム32点がプリセットで入っています

## 使い方

1. 公開ページを開く: https://matsuo474-dotcom.github.io/camp-packing-list/
2. 左のサイドバーでリストを切り替え、「＋ 新しいリスト」で新しいリストも作れます（スマホでは左上の「☰」から開きます）。サイドバーの数字は未チェックのアイテム数です
3. アイテムの「＋子」ボタンで子アイテムを追加できます
4. 家族に教えるときは「共有リンクをコピー」でリンクを送る

リンクを知っている人は誰でもリストを見たり編集したりできます。
